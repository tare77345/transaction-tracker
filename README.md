
# Transaction Tracker

A simple and responsive transaction tracker built with HTML, CSS, and JavaScript.

## 🚀 Live Demo

[View the live application](https://tare77345.github.io/transaction-tracker/)

## 📋 About

Transaction Tracker allows users to manage their income and expenses directly in the browser.

Transactions are saved using the browser's `localStorage`, so the data remains available after refreshing the page.

## ✨ Features

* Add income and expense transactions
* Edit existing transactions
* Delete transactions
* Reset all transactions
* Calculate total income
* Calculate total expenses
* Calculate current balance
* Form validation
* Confirmation before deleting transactions
* Persistent data using `localStorage`
* Responsive design for desktop and mobile

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Browser `localStorage`
